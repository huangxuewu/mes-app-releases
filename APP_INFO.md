# Edit app information without an APK release

Each app maintains its own `store/app-info.json` and `store/help.md` in its source
repository. MES Store is a consumer of that information. The public per-app files
and combined [`app-info.json`](app-info.json) feed are generated by publication;
do not author app information in the combined file.

| App | Owning source repository | Published information |
| --- | --- | --- |
| Dispatcher | [mes-dispatcher](https://github.com/huangxuewu/mes-dispatcher/tree/main/store) | [Dispatcher](apps/dispatcher/app-info.json) |
| MES Radio | [mes-radio](https://github.com/huangxuewu/mes-radio/tree/main/store) | [Radio](apps/radio/app-info.json) |
| MES Run Beta | [mes-run](https://github.com/huangxuewu/mes-run/tree/main/store) | [Run](apps/run/app-info.json) |
| MES Store | [mes-app-store](https://github.com/huangxuewu/mes-app-store/tree/main/store) | [Store](apps/store/app-info.json) |
| SignPad | [mes-signature-pad](https://github.com/huangxuewu/mes-signature-pad/tree/main/store) | [SignPad](apps/signpad/app-info.json) |
| Time Punch | [mes-time-punch](https://github.com/huangxuewu/mes-time-punch/tree/main/store) | [Time Punch](apps/time-punch/app-info.json) |

Source repositories are private. Only the app information and help page are copied
to this public repository. From the owning source checkout, validate using the
existing sibling MES Store publishing tools:

```powershell
python ../mes-app-store/tools/publish_store_info.py .
```

Commit and push the app's source files, then publish their reviewed content:

```powershell
python ../mes-app-store/tools/publish_store_info.py . --publish
```

This updates only the owner's `apps/<slug>/app-info.json`, `help/<slug>.md`, and
its entry in the combined feed, in one GitHub commit. Other app information and APK
metadata remain intact. The publisher rebases unrelated concurrent publications
and refuses a conflicting change to the same app. Existing Git credentials are used.
A source commit alone does not deploy; run the publish command after committing.

MES Store 1.2.19 and later continue to read the same combined feed, so this ownership
change requires no APK update. Pull down on Featured or Apps to refresh; automatic
checks also fetch it. GitHub's cache can take a few minutes to serve a new commit.

Each source file has `schemaVersion: 1` and an `apps` array containing exactly one
entry for its registered Android `packageName`, which must stay unchanged. The
publisher checks the source Git remote against MES Store's `app-sources.json` registry.

| Field | Where it appears | Maximum length |
| --- | --- | --- |
| `name` | App name throughout the store | 80 |
| `intro` | App list, search, and app details | 280 |
| `featured.eyebrow` | Small heading on the Featured card | 60 |
| `featured.headline` | Main Featured headline; `\n` adds a line break | 100 |
| `featured.description` | Supporting Featured paragraph | 600 |
| `featured.actionLabel` | Featured card action, which opens app details | 32 |
| `link.label` | External website/help button on app details | 60 |
| `link.url` | HTTPS website or help-page destination | 2048 |

Use `"link": null` or remove `link` to hide the external button. Links must use HTTPS,
without embedded credentials or custom ports. The default destinations are the
Markdown pages in [`help/`](help/); edit the owning repository's `store/help.md` to
update them. Replace the link with your own website URL in `store/app-info.json`
at any time. Use public information only: this repository and its content are public.

Keep `schemaVersion` at `1`, use valid JSON, and include all four Featured text fields
for each entry. Invalid content is rejected as a whole and the last valid copy is kept.
On first launch without a network, the app uses its bundled copy. An app missing from
this file uses its catalog name and description with a generic Featured heading.

This file cannot change APK downloads, versions, checksums, or signing certificates.
Those remain in `catalog.json` and the verified release workflow. The app's screenshot
images/captions, icons, card artwork, and layout are still bundled in the APK.
Publishing another APK does not change the editorial feed. MES Store's bundled
`app/src/main/assets/app-info.json` is only an offline snapshot for a new installation;
it is not an authoring source. Refresh that snapshot from the generated feed when
preparing a future Store binary.

Write each app's introduction around a concrete reason to use it. Give Featured its
own headline and paragraph instead of repeating the list introduction. Match the
voice to the work: dispatch planning, a quick conversation, a production shift,
shipment paperwork, or a personal time record.
