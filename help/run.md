# MES Run Beta

Give every shift a shared picture of production.

Explore production lines, floor staffing, and lot history together. Use the beta
to review how the day's work and people fit across the floor.

Version 0.1.0-beta.25 uses the production MES service. Sign in with your existing authorized supervisor PIN. Production actions operate on live MES records.

Beta 25 replaces an unavailable Android signing key. Uninstall the older app before installing Beta 25; uninstalling deletes local settings, drafts and pending actions. Server-side records remain. Review pending work before uninstalling.

Updates and version-specific testing notes are available in MES Store.
