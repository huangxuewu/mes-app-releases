# MES Store

Your workplace apps, without the hunt for download links.

- **Featured** introduces the apps and why you might need them.
- **Apps** lets you search, install, or update an app. Open an app page for screenshots and release notes.
- **Tutorial** contains workplace guides.
- **Settings** controls automatic update checks and downloads.

Pull down on Featured or Apps to refresh. App introductions and help links refresh
alongside the catalog; the last saved information remains available offline.
Opening an external help page needs a browser and normally an internet connection.

Android asks you to confirm app installation. If requested, allow MES Store to
install apps from this source. Install updates over the existing apps to retain data.
Each MES app still requires its own workplace authorization.
