# SignPad

Finish the paperwork while the shipment is still in front of you.

Use SignPad to capture the required bill-of-lading signatures for a shipment.
Open the correct shipment, review the document, and follow the signing prompts.
Check the signed document before completing the handoff.

For the illustrated walkthrough, open **MES Store → Tutorial → How to use SignPad**.
Use your workplace's MES authorization and server settings. Ask your administrator
if the shipment or signing workflow is unavailable.

Install updates over SignPad; do not uninstall it to work around an update problem.
